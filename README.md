# AI Resume Analyzer

## 📌 About the Project
AI Resume Analyzer is a web application built using Python and Flask.

It allows users to:
- Upload their resume (PDF or DOCX)
- Paste a job description
- Get a match score
- See missing skills
- Get suggestions to improve their resume

---

## 🚀 Features
- Resume Upload
- Job Description Analysis
- Resume Matching Score
- Missing Skills Detection
- Improvement Suggestions

---

## 🛠 Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- spaCy (NLP)
- PyPDF2
- python-docx

---

## ⚙️ How to Run the Project

1. Install required libraries:
   pip install flask spacy PyPDF2 python-docx

2. Download spaCy model:
   python -m spacy download en_core_web_sm

3. Run the project:
   python app.py

4. Open in browser:
   http://127.0.0.1:5000/
